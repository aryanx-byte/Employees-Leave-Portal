Employee Leave Portal
📌 Project Overview

The Employee Leave Portal is a web-based application that helps organizations manage employee leave requests efficiently. Employees can apply for leave online, track the status of their requests, and view their leave history. Administrators or managers can review, approve, or reject leave applications through a centralized dashboard.

This project simplifies the leave management process, reduces paperwork, and improves communication between employees and management.
